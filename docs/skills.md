## 技术栈一览

```text
🔴 模拟 & 混合信号设计
├── Python (行为建模与分析)
├── MATLAB (验证与仿真)
├── SPICE / Verilog-A (电路仿真)
└── Excel (快速分析与表征)

🟢 数字设计与验证
├── SystemVerilog (RTL 设计与测试台)
├── VHDL (硬件描述语言)
├── Verilog (数字逻辑)
└── 形式化验证方法

🔵 人工智能 & 机器学习
├── Python (TensorFlow, PyTorch, NumPy)
├── 深度学习理论与实现
├── LLM 微调与部署
└── 计算机视觉与 NLP

🟣 开发工具 & 环境
├── Git & GitHub (版本控制)
├── Docker (容器化)
├── EDA 工具 (Cadence, Synopsys)
└── Linux & Shell 脚本
```
